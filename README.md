\# Student Management System



\## Features

\- Add, Update, Delete Students

\- Search Functionality

\- Export to CSV

\- MySQL Database Integration

\- Input Validation



\## Tech Stack

\- Python (Tkinter)

\- MySQL

\- dotenv



\## Setup Instructions

1\. Install dependencies

2\. Configure .env

3\. Setup MySQL database

4\. Run main.py
